## 1. O que mudou

No cabeçalho de **todas as telas**, no canto superior direito, agora aparece:

`Victor • Administrador   [ Sair ]`

Ao clicar em **Sair**:

1. o botão vira **"Saindo..."**, para a pessoa não clicar duas vezes;
2. o sistema encerra a sessão no Supabase com `supabase.auth.signOut()`;
3. a pessoa vai para a **tela de login**.

## 2. Por que funciona em todas as telas

Todas as telas internas usam o mesmo "molde", o `AppShell.jsx`, que desenha o menu lateral e o cabeçalho. Colocando o botão no molde, ele aparece em todas as telas de uma vez, sem mexer em cada uma.

## 3. Detalhes técnicos

- **`signOut()`** apaga a sessão guardada no navegador. Depois disso, o `AuthContext` percebe que não há mais sessão.
- **Proteção extra:** mesmo que alguém aperte "voltar" no navegador, o `RequireAuth` manda de volta para o login.
- **`navigate("/", { replace: true })`** troca a página atual pelo login no histórico do navegador, em vez de acrescentar uma página nova. Assim o "voltar" não reabre a tela interna.

## 4. Como testar

1. Entre no sistema, clique em **Sair** e confira que voltou para o login.
2. Aperte **voltar** no navegador: deve continuar no login, sem abrir a tela interna.
3. Entre de novo normalmente.
