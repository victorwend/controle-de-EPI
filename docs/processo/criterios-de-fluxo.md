# Critérios do fluxo

## Definition of Ready

- [ ] Objetivo claro
- [ ] Requisito e regra identificados
- [ ] Critérios de aceite verificáveis
- [ ] Dependências resolvidas
- [ ] Figma identificado, quando aplicável
- [ ] Contrato de API definido, quando aplicável
- [ ] Risco e segurança avaliados
- [ ] Estimativa revisada
- [ ] Nenhuma decisão essencial pendente

## Definition of Done

- [ ] Implementação concluída
- [ ] Critérios de aceite comprovados
- [ ] Testes automatizados aprovados
- [ ] Teste manual executado quando necessário
- [ ] Segurança e permissões verificadas
- [ ] Pull Request revisado
- [ ] Apontamentos corrigidos
- [ ] Documentação atualizada
- [ ] Evidência registrada
- [ ] Ambiente e versão registrados
- [ ] Nenhum segredo ou dado real indevido incluído
